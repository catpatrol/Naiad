# drops/ — convention

1. Raw operator inbox. Drag artifacts in exactly as they come — no renaming, no formatting, no cleanup.
2. HERMES names them per standing rule G-11 and files them to their destination; he never re-authors content.
3. A drop is transient: once filed, it leaves this folder. A drop still here is a drop still unprocessed.
4. Content guard applies (text only, 1 MB cap) — oversize artifacts get a `path` + `sha256` pointer file instead.
5. Nothing here is authoritative until Hermes files it; treat the contents as unverified inbound.
