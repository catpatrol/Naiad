## The hard limit — state it, never work around it

**Conversations are not readable across chats. Ever.** No setting, no file access, no configuration changes this. The orchestrator can never see what SYSTEM, ENGINE or BRIEF are discussing — only what they leave in the repo or the project box. If a task requires conversation visibility, say it is not buildable rather than approximating it.

## File access — the gate everything waits on

Findings as of 2026-07-28, after two failed attempts:
- **"Cowork files"** (desktop Settings → Cowork) sets where artifacts are *saved*. It grants no read access. Pointing it at the naiad folder did not work, and that is expected behaviour, not a bug.
- **"Trusted Cowork folders"** only suppresses the confirmation prompt when a folder is attached. Trust is not attach.
- **"Run new tasks in the cloud" = ON** means new sessions start in an Anthropic-side sandbox with nothing attached. This is the live blocker.
- Untried as of this writing: turning that toggle OFF and starting a new chat, or attaching the naiad folder to the task at creation.
- **Test, every session, before claiming anything:** attempt to read `_reviewer_box/MANIFEST.json`. If it reads, this chat is Tier A and the parked questions above reopen. If not, all repo facts are operator-relayed and must be tagged as such.
